# 🎓 Course Recommendation System

A Python-based **Course Recommendation System** that helps users discover relevant online courses using course similarity and popularity. Built with **Tkinter**, **Pandas**, and **Scikit-learn**, the application features a modern dark glass-style GUI with interactive buttons and course search functionality.

## ✨ Features

- 🔍 **Course Search:** Search for courses using a searchable dropdown.
- 🎯 **Personalized Recommendations:** Find similar courses based on course titles and subjects.
- 📈 **Popular Courses:** Discover popular courses using subscriber and review data.
- 📂 **Dataset Loading:** Load a course dataset from a CSV file.
- 🖥️ **Modern GUI:** Clean interface with a dark glass-style theme.
- 🪟 **Resizable Window:** Supports window resizing with a minimum window size.
- ⚡ **Similarity Matching:** Uses text vectorization and cosine similarity to identify related courses.
- 📊 **Dataset Statistics:** Displays the number of courses and subject areas.

## 🛠️ Technologies Used

- **Python** — Core programming language
- **Tkinter** — Graphical user interface
- **Pandas** — Dataset loading and data processing
- **Scikit-learn** — Text vectorization and similarity calculation

## 📋 Requirements

Before running the project, make sure you have:

- Python 3.9 or later
- A compatible operating system (Windows, macOS, or Linux)
- A course dataset in CSV format

## 📊 Dataset

The application uses a CSV dataset containing course information.

## 🚀 How to Use

1. Start the application.
2. Load your course dataset if it has not loaded automatically.
3. Search for or select a course from the dropdown.
4. Click **Recommend courses** to discover similar courses.
5. Click **Popular courses** to explore courses ranked by popularity.
6. Review the displayed course titles and similarity scores.

## 🎨 User Interface

The application uses a modern dark-themed interface with:

- Dark glass-style colors
- Interactive buttons
- Course selection and search
- Recommendation cards
- Dataset statistics
- Status messages
